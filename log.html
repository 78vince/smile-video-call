💡 為什麼需要這套系統？

在日常照護長輩時，市面通訊軟體（LINE、FaceTime、Zoom、Google Meet）雖然功能豐富，但對年長者而言存在著巨大的數位鴻溝：

❌ 市售通訊軟體的長輩痛點

  • • 操作選單層級深，常常找不到視訊按鈕
  • • 平板久放容易跳出密碼驗證或被強制登出
  • • 來電時滑動解鎖不靈敏，長輩常常手忙腳亂
  • • 開會軟體動輒要求「主辦人 / 會議主持人登入」
  • • 長輩不知道誰打來，也沒有自動接通機制

✅ 微笑視訊的核心解答

  • • 超大照片與姓名：一眼看懂，點照片立即通話
  • • 永遠常亮不休眠：透過 WakeLock 鎖定螢幕
  • • 5 秒自動接通：晚輩撥號，長輩端完全免按鍵自動開鏡頭
  • • 免主持人開源伺服器：徹底消除登入認證卡點
  • • 家庭 LINE 群組聯防：一撥號全家同步叮咚提醒

🏗️ 系統整體架構與運作原理

系統由三個關鍵骨幹緊密咬合，實現毫秒級信號傳遞與無障礙視訊通話：

📹 開源視訊引擎
Jitsi Meet (jitsi.riot.im)
開源社群維護的公開伺服器。免登入、無 Google/GitHub 主持人身分限制，進入房間瞬間啟用視訊與麥克風。
📡 雙向即時信號通道
ntfy.sh (Server-Sent Events)
長輩平板待機時透過 SSE 保持連線。晚輩一撥號，信號在 0.2 秒內廣播至平板觸發自動接聽、忙線提示與同步掛斷。
🤖 LINE 群組中繼站
Google Apps Script (GAS)
零伺服器成本的雲端 Webhook。自動學習家庭群組 ID，並調用 LINE Messaging API 將通話一鍵直通連結推播至家庭群組。

🚀 七大開發演進里程碑 (Milestones)

Phase 1
PWA 離線漸進式架構與長輩大按鈕介面
建立 Service Worker 離線快取機制與 Web Manifest，支援安裝至 Android 平板主畫面。採用 28px 超大圓角高對比卡片、110px 大頭貼、全螢幕時鐘與日曆，並整合 Screen Wake Lock 防止螢幕休眠。
PWA Service Worker Screen WakeLock Dicebear Avatars
Phase 2
攻克 Jitsi 主持人登入限制（遷移至 jitsi.riot.im）
針對官方 meet.jit.si 強制要求 Google 登入主持人的痛點，徹底切換至免認證開源伺服器 jitsi.riot.im，同時隱藏 Jitsi 所有複雜工具列，消除所有可能讓長輩困惑的操作。
Jitsi External API 無登入伺服器 自動開鏡頭
Phase 3
以長輩為中心的多角色家庭架構（阿笑 ↔ 阿禮、阿龍、小君）
構建 1 位長輩對應 3 位晚輩的專屬網址架構（?u=axiao、?u=ali、?u=along、?u=xiaojun）。支援 join 參數一鍵快速通關，晚輩點開通知直接進房，無須手動重複撥打。
多身分 URL 架構 一鍵直通 Auto-Join 專屬獨立房間
Phase 4
即時信號通道與長輩端「5 秒倒數自動接聽」
整合 ntfy.sh 雲端通道。晚輩撥號時長輩平板即時響起自製 Web Audio 和弦鈴聲，並浮現 5 秒自動接聽倒數條。秒數歸零後平板自動調用 Jitsi API 加入視訊，達成真正的長輩零手動操作。
ntfy.sh SSE 自動接聽 Auto-Answer Web Audio API
Phase 5
消滅「雙媽媽幽靈分身」與通話中忙線保護
掛斷時延遲 500ms 釋放 DOM，確保伺服器離線封包送達，消滅幽靈分身；若長輩已在通話中，其他晚輩打來會收到「長輩通話中」提示且不打擾現有通話；晚輩掛斷時，長輩端自動退出視訊乾淨返回首頁。
幽靈分身消除 忙線保護 Busy Protection 遠端同步掛斷
Phase 6
常駐底欄鎖定與平板矮螢幕響應式優化
修復 Flexbox 導致底欄被擠出螢幕外的邊界問題，為底部狀態列加上 flex-shrink: 0 與專屬白色浮雕卡片；頂部時鐘與重新整理按鈕改為橫向並排；加入專屬矮螢幕自適應，橫向直向平板皆能一屏完整收納。
常駐底欄 Docked Footer 矮螢幕響應式 PWA 強制刷新按鈕
Phase 7
LINE Messaging API + Google Apps Script (GAS) 智慧群組中繼站
全面取代即將停用的 LINE Notify，建立免費 Google 雲端中繼站。支援機器人進群自動學習綁定群組 ID，並將 Webhook 寫入前端核心，長輩點擊任一位家人，家庭 LINE 群組全員立刻收到直通來電通知。
LINE Messaging API Google Apps Script 家庭群組自動綁定 全家統一推播
