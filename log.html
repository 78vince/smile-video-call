💡 為什麼需要這套系統？

在日常照護長輩時，市面通訊軟體（LINE、FaceTime、Zoom、Google Meet）雖然功能豐富，但對年長者而言存在著巨大的數位鴻溝：

❌ 市售通訊軟體的長輩痛點

  • • 操作選單層級深，常常找不到視訊按鈕
  • • 平板久放容易跳出密碼驗證或被強制登出
  • • 來電時滑動解鎖不靈敏，長輩常常手忙腳亂
  • • 開會軟體動輒要求「主辦人 / 會議主持人登入」
  • • 長輩不知道誰打來，也沒有自動接通機制
  • • 平板待機休眠後黑屏，長輩誤以為故障

✅ 微笑視訊的核心解答

  • • 超大照片與姓名：一眼看懂，加大無框設計
  • • 微光時鐘防呆喚醒：防烙印、插電常亮、碰觸喚醒不誤撥
  • • 5 秒自動接通：晚輩撥號，長輩端完全免按鍵自動開鏡頭
  • • 免主持人開源伺服器：徹底消除登入認證卡點
  • • 家庭相簿輪播：平時是一台溫馨的家庭數位相框
  • • 家庭 LINE 群組聯防：一撥號全家同步收到直通通知

🏗️ 系統整體架構與運作原理

系統由四個關鍵骨幹緊密咬合，實現毫秒級信號傳遞與無障礙視訊通話：

📹 開源視訊引擎
Jitsi Meet (jitsi.riot.im)
開源社群維護的公開伺服器。免登入、無 Google/GitHub 主持人身分限制，進入房間瞬間啟用視訊與麥克風。支援視訊與純語音雙模式。
📡 雙向即時信號通道
ntfy.sh (Server-Sent Events)
長輩平板待機時透過 SSE 保持連線。晚輩一撥號，信號在 0.2 秒內廣播至平板觸發自動接聽、忙線提示與同步掛斷。
🤖 LINE 群組中繼站
Google Apps Script (GAS)
零伺服器成本的雲端 Webhook。自動學習家庭群組 ID，並調用 LINE Messaging API 將通話一鍵直通連結推播至家庭群組。
🖼️ 家庭相簿與微光防烙印
PWA + Google Photos + WakeLock
平時自動輪播家庭照片；3 分鐘閒置自動進入微光防烙印時鐘，碰觸螢幕 800ms 防呆攔截，喚醒絕不誤觸撥號。
