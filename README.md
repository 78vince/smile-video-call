## ⚡ 三大升級亮點

### 1. 🔄 「強制重新整理」按鈕（專門解決 PWA 應用更新問題）
* 在右上角新增了 **`🔄 重新整理`** 快捷鈕。
* 點擊後會自動註銷舊的 Service Worker、清空瀏覽器快取儲存，並強制向 GitHub 請求最新程式碼！
* 解決平板在安裝為桌面 App 後難以手動更新快取的問題。

### 2. 📞 晚輩撥號時，長輩平板「自動接聽」
* 當阿禮、阿龍或小君在手機按下【阿笑媽媽/奶奶】時：
  1. 系統透過即時通道發送信號給長輩平板。
  2. 平板**大聲響起電話鈴聲**，螢幕顯示來電者照片與「👦 阿禮 來電中...」。
  3. **倒數 5 秒自動接聽**（也可直接按綠色「馬上接聽」），鏡頭與麥克風自動啟動！長輩無須觸碰螢幕即可接通。

### 3. 💬 支援 LINE 訊息通知（透過 Google Apps Script）
* 專案內已提供完整開源的 `google-apps-script-line.js`。
* 只要將該檔案複製到免費的 [Google Apps Script](https://script.google.com/) 部署為網頁應用程式，即可填入後台設定。
* 長輩按通話時，晚輩的個人 LINE 或家庭 LINE 群組會立即收到通話推播！
