# 😊 Smile Video Call (微笑視訊) - 家庭互通雙向視訊系統

以**長輩阿笑**為中心的多角色視訊通話 PWA。每個家人都擁有專屬身分網址與一鍵通話按鈕，房間互通且支援個別手機通知！

---

## 🔔 個別推播通知機制

* **阿笑撥打【阿禮】** ➜ 訊息推播到 **阿禮** 的 Discord / 頻道。
* **阿笑撥打【阿龍】** ➜ 訊息推播到 **阿龍** 的 Discord / 頻道。
* **阿笑撥打【小君】** ➜ 訊息推播到 **小君** 的 Discord / 頻道。
* 晚輩點開通知內的專屬房間連結，雙方立即在同一個房間通話！

可在右下角 **⚙️ 齒輪設定 ➜ 個別通知設定** 中隨時修改每個人的 Webhook 網址。
