# 😊 Smile Video Call (微笑視訊) - 長輩專用一鍵通話 PWA

專為高齡長輩與幼童設計的「極簡一鍵視訊通話系統」。透過免帳號、免額外安裝 App 的 Jitsi Meet 雲端架構與 PWA 全螢幕技術，長輩只要在平板上點一下家人的大照片，就能直接開啟視訊對話！

---

## ✨ 核心特色

1. **極致單純**：螢幕上只有大大的家人照片與名字，點擊直接視訊，通話結束自動回首頁。
2. **免帳號、免登入**：長輩不需要申請 Google / LINE 帳號，不用記密碼。
3. **PWA 全螢幕獨立運行**：安裝在平板桌面後，自動隱藏瀏覽器網址列與分頁，防止長輩誤觸。
4. **內建撥號音效**：使用 Web Audio API 合成愉悅和弦與電話撥號聲，提供長輩明確的點擊觸感回饋。
5. **雙重防呆掛斷**：畫面上常駐大紅色「📞 掛斷電話」懸浮鈕，不用擔心長輩找不到小按鍵。
6. **手機即時推播通知**：長輩點擊通話時，可自動發送 Discord / Telegram / 自訂 Webhook 訊息到晚輩手機，點開通知直接進房間。
7. **防止螢幕休眠**：內建 Screen Wake Lock API，維持通話中螢幕常亮。
8. **家屬後台管理**：點擊右下角齒輪 ⚙️ 即可即時修改家人名稱、照片、房間代碼與通知設定。

## 🌐 免費雲端部署教學（只要 3 分鐘）

因為本系統是純靜態前端網頁，推薦使用以下任一免費服務（自帶永久免費 HTTPS）：

### 方法 A：使用 GitHub Pages（最推薦）
1. 在 GitHub 上建立一個新的公開或私有儲存庫（Repository），例如 `smile-call`。
2. 將本專案的所有檔案上傳或 Push 至該儲存庫。
3. 進入儲存庫的 **Settings ➜ Pages**。
4. 在 **Build and deployment** 的 Source 選擇 `Deploy from a branch`，Branch 選擇 `main` / `root` ➜ 按下 **Save**。
5. 等待 1 分鐘，即可獲得您的專屬網址：`https://<你的帳號>.github.io/smile-call/`。

### 方法 B：使用 Vercel 或 Netlify
1. 前往 [Vercel](https://vercel.com) 或 [Netlify](https://www.netlify.com)。
2. 直接將此專案資料夾拖曳（Drag & Drop）上傳，即可立即產生一組專屬 HTTPS 網址。

## 📱 Android 平板安裝至桌面步驟（長輩機設定）

取得上述部署好的 HTTPS 網址後，拿起 Android 平板進行一次性設定：

1. **以 Chrome 開啟網址**：在平板的 Chrome 瀏覽器輸入您的網址。
2. **安裝為桌面 App**：
   * 點選瀏覽器右上角的選單圖示（**⋮**）。
   * 選擇 **「安裝應用程式」** 或 **「新增至主螢幕」**。
   * 平板桌面上會出現「微笑視訊」的大圖示。
3. **授權相機與麥克風**：
   * 從桌面點開「微笑視訊」App。
   * 隨意點擊一個聯絡人測試，系統會詢問「是否允許使用相機與麥克風？」。
   * **務必勾選「允許」，並選擇「記住此設定」**。
4. **防誤觸小技巧（螢幕固定）**：
   * 進入 Android 系統設定 ➜ **安全性** ➜ **螢幕固定（App Pinning）** 開啟。
   * 將「微笑視訊」固定在螢幕上，長輩就完全不會誤跳回 Android 系統桌面！

## 🔔 設定手機即時通知（長輩撥號時通知晚輩）

如果想在長輩按下按鈕時，讓您的手機立刻收到通知：

1. 在網頁首頁右下角點擊 **⚙️（齒輪）** 開啟家屬設定。
2. 切換到 **「🔔 手機推播通知」** 分頁。
3. 勾選 **「啟用手機通知功能」**。
4. 選擇 **Discord 頻道 Webhook**（最容易）：
   * 在你的 Discord 伺服器任一頻道 ➜ 編輯頻道 ➜ 整合 ➜ Webhook ➜ 建立 Webhook ➜ 複製網址。
   * 貼到設定欄位中。
5. 按下 **「🔔 測試發送通知」**，確認手機 Discord 是否跳出訊息。
6. 點擊 **「儲存並套用」** 即完成！
